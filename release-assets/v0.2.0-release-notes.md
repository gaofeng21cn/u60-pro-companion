# U60 Pro Companion v0.2.0

U60 Pro Companion 的首个独立公开版本，面向中兴 U60 Pro 国行 B28 / B31。

## 本版内容

- 原厂共存小屏，提供“深色”和“浅色”两个主题。
- 小屏总览、网络、Clash / Mihomo、Tailscale、套餐台账和 eSIM 入口。
- 移动终端认证状态保持，改善中国移动终端持续联网体验。
- Tailscale 组网、Wi-Fi 接力和蜂窝回退策略。
- B31 原厂 ECM＋ADB，支持 macOS 数据线直连联网。
- eSIM 卡片读取、配置文件下载与管理、运营商通知。
- 设备绑定安装、原地升级、回退备份和上传包清理。
- 套餐流量账本支持固定周期、额度、有效期和 SIM 卡槽归属。

## 安装

下载 `u60-pro-enhanced-v0.2.0-companion.tar.gz` 与 `SHA256SUMS.txt`，校验后按 [README](https://github.com/gaofeng21cn/u60-pro-companion/blob/main/README.md) 和 [安装说明](https://github.com/gaofeng21cn/u60-pro-companion/blob/main/docs/INSTALL.md) 执行设备绑定、检查、安装和启动。

当前安装包继续使用 `u60-pro-enhanced-*` 目录和 `/data/u60-panel` 兼容标识，已安装设备可以按原地升级流程更新。

## 来源

项目早期从 `defilippisprafka-netizen/u60-pro-enhanced` fork，随后独立维护，并吸收多个 GitHub 开源项目的实现经验。来源和许可见仓库中的 [UPSTREAM-LEARNING.md](https://github.com/gaofeng21cn/u60-pro-companion/blob/main/docs/UPSTREAM-LEARNING.md) 与第三方声明。
