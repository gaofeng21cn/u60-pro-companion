# U60 Pro Companion v0.2.2

这是安装前置检查的兼容性修复，包含 v0.2.1 的小屏锁屏修复。

## 修复

- 修复 USB 数据链路已正常枚举、但设备未处于充电状态时，`upgrade-check` 被“USB 未连接”误拒绝的问题。
- 检查现在接受 `CONFIGURED` 的 Android USB 或 UDC 数据链路；真正未连接时仍会拒绝安装。
- 继续包含 v0.2.1 的启动/唤醒锁屏，以及自动熄屏关闭背光的行为。

## 安装

下载 `u60-pro-enhanced-v0.2.2-companion.tar.gz` 与 `SHA256SUMS.txt`，校验后按[安装说明](https://github.com/gaofeng21cn/u60-pro-companion/blob/main/docs/INSTALL.md)执行。

已安装旧版的设备需要先从本版包重新运行只读 `prepare.py`，再进入新生成的私有目录执行 `upgrade-check` 和 `upgrade`。不要复用旧准备目录。

## 验证范围

本版通过安装/升级门禁专项回归和完整主机回归；在 B31 上以 USB 已枚举、未充电的实际状态验证前置检查。锁屏在真实 U60 Pro 上的启动、唤醒、轻触解锁和实体触摸手感仍需安装后验收。
