# U60 Pro Companion v0.2.1

这是 v0.2.0 的小屏锁屏热修版。

## 修复

- 修复 v0.2.0 中小屏锁屏只存在于预览、正式程序从未进入锁屏的问题。
- 增强界面启动后先显示锁屏；熄屏后按电源唤醒也会回到锁屏，轻触进入主界面。
- 自动熄屏仍关闭背光，锁屏只隐藏主界面，不替代设备认证或访问权限。

## 安装

下载 `u60-pro-enhanced-v0.2.1-companion.tar.gz` 与 `SHA256SUMS.txt`，校验后按 [安装说明](https://github.com/gaofeng21cn/u60-pro-companion/blob/main/docs/INSTALL.md) 执行。

已安装 v0.2.0 的设备进入准备阶段生成的私有目录，执行：

```sh
python3 deploy-from-computer.py upgrade-check
python3 deploy-from-computer.py upgrade
```

升级前先在界面关闭 Mac USB 联网，并等待原厂 USB 模式恢复。

## 验证范围

本版通过完整主机回归、原生小屏渲染检查和 Zig 0.14.1 ARM64 构建。锁屏在真实 U60 Pro 上的启动、唤醒、轻触解锁和实体触摸手感仍需安装后验收。
