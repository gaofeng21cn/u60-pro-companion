# U60 Pro 极光信标小屏候选 · R2

这是 2026-10-23 的第二版审阅稿。仍未安装到设备，没有合并、推送或替换当前界面。

## 本轮调整

主页的信息层级重新整理为：

1. 主卡合并网络、信号质量、实时上下行与速率曲线；
2. 今日/本周期流量与连接设备并列为次卡；
3. 代理与组网、Wi-Fi/USB 收为紧凑状态行。

设置入口保留六宫格，但统一为原生线条图标和相同的卡片内边距。设置详情由四张独立大卡改为一张分组卡内的四行操作，减少重复边框和无效空白。

## 间距规则

- 页面左右外边距：16px；内容可用区域为 16..304。
- 并排卡片间隔：10px。
- 卡片左右内边距：16px。
- 设置七宫格使用 `(288 - 10) / 2` 的等宽栅格。
- 行内值右侧为箭头预留 11px 安全区，避免数值被误读成带标点。
- 底部导航热区仍为 44px 高；选中背景与标签统一上移，不贴屏幕下沿。
