# U60 Pro 小屏候选 · R4 原厂深色

本版以 2026-10-23 当前这台 B31 的原厂小屏为配色依据。已通过 USB 读取原厂锁屏、仪表盘主页和解锁菜单：背景为黑色，菜单为中性深灰卡片和白字；速率以黄色表示上传、绿色表示下载，电池使用蓝色，菜单图标各有小面积强调色。原厂网页的蓝白配色与本次要求无关；此前 R3 的配色依据已废止。

本目录仅含合成数据的候选预览、源码补丁与说明。原厂实机截图、含热点二维码的菜单截图、原厂字体和二进制留在本机临时诊断目录，不并入本目录，也不进入 Git。

## 视觉与布局

- 黑色背景 `#000000`、中性深灰卡片 `#181818`、白色正文、浅灰辅助信息；普通操作使用蓝色。颜色经设备的 RGB565 格式量化。
- 上传黄 `#FFCE00`、下载绿 `#6AF200` 来自当前设备锁屏采样；主页速率数值保持白色，方向与标签承载语义颜色。
- 设置入口仅图标使用小面积彩色，整张卡片保持中性；去掉亮边框和背景光晕。
- 页面左右边距、卡片左右内边距均为 16px。顶部状态行 y=50、首卡 y=80，按 14px 文本布局保留 16px 净空；主页卡片间距 12px、并排间距 10px。
- 保留等宽上下行区域、流量与连接设备次级卡片、独立的代理和共享入口，以及设置六宫格与 64px 详情行。
- 继续使用原生圆角、线条和圆环抗锯齿。本次预览直接加载本设备的 ZTEZhengYuan 字体；未使用替代字体。

## 交互候选

- 按下后立即出现轻微明度反馈；抬起后才执行动作。手指移出点击范围形成拖动时，取消按压和点击，避免滑动误触。
- 标签切换、进入/返回详情使用横向短过渡，分页使用纵向短过渡。程序时长为 160ms，缓动结束；页眉与底栏保持固定。弹窗、键盘、锁屏和后台状态刷新不套用导航过渡。
- 过渡复用两张已经绘制完毕的画面，不逐帧重新生成文字。手指再次接触时结束过渡，输入优先；过渡完成后不继续刷新。
- 重复字形缓存抗锯齿遮罩，减少重绘时的重复生成与内存分配；缓存不保存颜色，切换主题及按压状态时仍按当前背景合成。缓存上限为 512 个字形，每个遮罩最多 4096 字节。
- 有输入或过渡时推迟常规状态采样；操作与状态读取继续沿用现有后台处理。没有新增常驻服务或空闲动画。

`interaction.gif` 来自同一原生画面合成函数的逐帧输出，为方便观察，将 160ms 过渡放慢到约 300ms 并停留。它是候选交互示意，不是设备录像；真实屏幕提交耗时、帧间隔、触摸延迟和实体手感尚未验收。

## 开机时间核对

检查时原厂小屏时间与主机北京时间一致，原厂 SNTP 同步状态为完成。该次开机日志中，约第 73 秒切换到自定义界面时仍为 00:01；说明界面交接早于本次校时完成。原厂先出现、稍后交给自定义界面，属于现有启动流程。

本次未重新开机，无法据此给出首次同步的准确延迟，也尚未修复原厂启动初期的时间显示。设备 RTC 仍从 1970 年计时；这不证明原厂 UI 直接读取 RTC。B31 已有特殊的系统时间/时区行为，因此没有修改系统时间、时区或 SNTP 配置。

候选中无效时钟显示 `--:--`，锁屏说明改为“等待网络校时”，避免把未校准的时间当作真实时间。
