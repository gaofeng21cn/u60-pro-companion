# U60 Pro 小屏候选 · R3 原厂蓝白

> 此版错误地参考了原厂网页配色，未满足“原厂小屏 UI 配色”的要求。配色依据已废止；请审阅相邻目录 `stock-screen-candidate-20261023-r4`，以下内容仅保留当时的版本记录。

本版按 2026-10-23 的最新要求，以原厂 UI 的蓝白方向重新配色，同时调整信息层级、排版和留白。参考截图用于布局研究；深蓝紫配色不是用户偏好。

配色取自本项目已与原厂网页对齐的 `web/factory/u60-enhanced.html`：主色 `#0f87f7`、正文 `#243746`、次要文字 `#627384`、细线 `#e2e8ef`。小屏使用浅灰底、白卡和蓝色强调，实际颜色经 RGB565 量化。

## 排版调整

- 顶部状态文字的布局高度为 14px，从 y=50 开始；第一张卡片从 y=80 开始，预留 16px 净空。主页预览回归检查中间有连续空白带。
- 左右页面边距与卡片左右内边距为 16px。主页卡片间距为 12px，并排卡片间隔为 10px。
- 主卡将网络制式、频段与信号收成一行，下载、上传使用等宽区域。详细信号读数保留在蜂窝详情；下载曲线保留在锁屏。
- 流量与连接设备并列，设备卡删除重复的“设备”尾行；流量卡补回可点击的账本入口。
- 代理卡明确标注组网状态。订阅余额在代理详情查看，Wi-Fi 和 USB 状态收成独立入口。
- 设置入口将图标、标题、说明纵向排列。详情以 64px 行高分组，名称和值留出间隔，操作箭头独立；操作提示只保留一处。套餐详情的两行说明单独计算卡片起点。
- 原生圆角、圆环与线条保留抗锯齿。页面背景为纯色，卡片为不透明白色。
