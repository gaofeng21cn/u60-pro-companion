## 设计边界

- 新增 `beacon` 作为第四个可选主题，原有 `classic`、`paper`、`seaglass` 保留。
- 沿用现有页面、动作参数、确认弹窗、表单、搜索、分页和原厂界面切换。
- 锁屏的“轻触进入”是界面层，不是设备安全认证；设备本身的登录与权限不变。
- 深色底使用静态极光缓存，没有新增动画或额外唤醒计时器。
- Beacon 的卡片圆角、状态环和速率曲线按像素覆盖做抗锯齿；设备仍只输出原生 RGB565，不引入高分辨率离屏合成。
- 首页速率曲线来自本地 `rx_bytes`/`tx_bytes` 的最近 32 个采样；没有历史数据时不绘制假曲线。
- 内存环、流量环分别绑定实时内存百分比和流量台账；读数未知时显示未知，不补造数值。
